How to read this

Before using this file, replace YOUR-FOLDER-NAME above with wherever you installed this package (e.g. counter, stats).

If the line above says "PHP IS ON" — everything works. The handler is active in this folder and the counter recorded this visit. Open the dashboard (index.php in your install folder) and you should see 1 page view for this file.

If it says just "Result:" with nothing after it — PHP is not running in this folder. .html files are still being served as plain files. Upload the phpcheck/ folder next to this file and open each phpcheck/t1/ through t7/ in turn — whichever one says "WORKS" tells you which handler line to use in root-htaccess-SNIPPET.txt.

If you can see PHP code on this page — the handler is pointed at the wrong PHP version. Check your host's PHP version selector (on cPanel this is called MultiPHP Manager) and change the handler line to match, or use the phpcheck/ folder described above to find the right one directly.

If you get a 500 error — the server rejected something in the .htaccess. Restore your backup.

Delete this file when you're done. (No need to delete install.php — it disables itself automatically once config.php exists.)
